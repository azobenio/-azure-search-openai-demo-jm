# 🚀 ChatBot JM - Assistant IA avec vos données

Application RAG (Retrieval-Augmented Generation) personnalisée utilisant Azure OpenAI et Azure AI Search.

## ✨ Fonctionnalités

- 💬 Chat intelligent avec vos documents
- 🔍 Recherche sémantique dans vos données
- 📊 Citations et sources pour chaque réponse
- 🎨 Interface personnalisée par Jean-Marie

## 🛠️ Technologies utilisées

- **Azure OpenAI Service** - Modèles GPT-4
- **Azure AI Search** - Indexation et recherche
- **Azure Container Apps** - Hébergement
- **React + TypeScript** - Frontend
- **Python FastAPI** - Backend

## 🚀 Déploiement

```bash
# Installation
git clone https://github.com/VOTRE_USERNAME/azure-search-openai-demo-jm.git
cd azure-search-openai-demo-jm

# Déploiement sur Azure
azd auth login
azd up
```

## 📝 Personnalisations

- Titre personnalisé : "ChatBot JM"
- Interface en français
- Données d'exemple : Northwind Health
